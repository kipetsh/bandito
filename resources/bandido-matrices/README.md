# Матрицы карт из cards_1.webp

Все 74 позиции исходной полосы сохранены в порядке сверху вниз, с повторами.
69 карт тоннелей + рубашка №70 + 4 стартовых варианта №71–74.
Это изображения Bandido/Bandida; в исходнике нет специальных карт Alcatraz.

Матрица: 3 строки × 6 столбцов; 1 — проход, 0 — стена.
Строки сверху вниз, столбцы слева направо. Все клетки квадратные.
Ориентация совпадает с исходником, без поворотов и отражений.
Фонарик в тупике считается частью прохода, не отдельной клеткой/выходом.

Стартовые карты представлены схемой связей выходов: форма самой камеры
не передаётся. №71/73 имеют 6 выходов, №72/74 — 5 (закрыт левый выход).
№71/72 — Bandido, №73/74 — Bandida. У рубашки №70 matrix=null.
Индексы выходов в JSON нулевые. sourceBox: [left, top, right, bottom],
правая и нижняя границы не включены.

cards-pixels.png — все схемы чёрным и белым, как в примере.
cards-comparison.png — оригиналы рядом со схемами для проверки.
cards.json — матрицы, выходы и координаты исходных изображений, а также
таблица pairs: строки каталога редактора. В shapes — одна или две схемы,
каждая списком одинаковых карт (с точностью до поворота на 180°).
kind: mirror — схема и её зеркальное отражение; similar — две
симметричные схемы, отличающиеся в наименьшем числе клеток; single —
симметричная схема без пары. Порядок: mirror, similar, single, внутри
— по наименьшему номеру; первой — схема с меньшим номером. Таблицу
проверяет тест по матрицам.
cards.ts — типизированный массив для TypeScript.
matrices.txt — все матрицы обычным текстом.
pixels/ — отдельные PNG 288×144, без сглаживания.
source-crops/ — вырезки исходного WEBP для всех 74 позиций.

Проверки: 73 матрицы правильной размерности; все тоннели связны.
С учётом поворота на 180° — 31 уникальная схема тоннелей:
24 по 2 экземпляра и 7 тупиков по 3 экземпляра, всего 69 карт.
Исходник имеет ширину всего 55 пикселей: это схемы проходов, а не
восстановленные изображения высокого разрешения.
